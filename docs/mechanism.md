# 機構とハードウェア

アップロードされたSTL(82,628三角形・54部品)を解析して生成した機構の記述です。
URDF・運動学・歩容の設計根拠はここにまとめてあります。

## 機構 (STL解析結果)

**12自由度 = 腰ロール×4 + 5節リンク脚(2サーボ)×4。全てDynamixel XL330-M288-T。**

各サーボはメッシュ内の出力軸ボス(φ16)とホーンねじ穴(4×φ2, PCD12)を検出して特定:

- **腰ロール**: 軸=X(前後方向)、位置(y=±70.23, z=97.0)。脚ユニット全体を横に振る
  → 足の横方向配置が可能になり、横歩き・低スリップ旋回を実現
- **脚リンク** (XZ平面の5節リンク、腰ロールと一緒に回転):
  - サーボ軸: 後脚 x=-49.95/-75.45、前脚 x=+59.05/+84.55 (z=90.5、ユニット座標)
  - クランク20.0mm ×2 → 脚上部ピン / 55.0mmロッド経由で脚下部ピン
  - 脚剛体: ピン間40.0mm + 足先延長(先端R7.5)

**脚の取付位置 (v4)**: 「四足ロボット2.stl」を参照し、脚アセンブリを腰XL330の
位置(32mm内側)に取付済み。脚平面はy=±101.4、駆動サーボが腰軸(y=±70.23)直上に
座る正しい構成。新旧STLの形状マッチング差分で移動部品を自動特定し、
ボディ側サーボ軸を基準にリンク部品を剛体変換で再組立て(`service/waist_build2.py`、
閉鎖誤差0.0000mm)。

## 重要: 技術ノート

1. **閉ループ**: URDFはツリーのみ表現可能なため5節リンクは脚下部ピン(L)で
   切ってあります。シミュレータ側で `conf/loop_constraints.json` の点対点拘束を
   必ず追加してください (`service/simulate.py` は自動)。Gazebo/MuJoCoならequality等で。
2. **PyBulletの慣性フラグ**: `URDF_USE_INERTIA_FROM_FILE` が無いとURDFの慣性値が
   無視され、軽量リンク+閉ループで拘束ソルバが発散して機構が崩れます。
3. **XL330-M288-T (5V)**: トルク上限0.45N·m(ストール0.52の85%)、速度上限
   10.8rad/s(無負荷103rpm)をモデル化。歩行時実測はトルクp95≈0.11N·m
   (≒定格連続0.10)、速度p95≈9.6rad/s。実機は負荷で速度が落ちるため
   まず低周波数(FREQ=1.0〜1.2)から試すのが安全。

## 歩容 (全方位トロット)

- ツイスト指令 (vx, vy, ωz) → 脚ごとのストライドベクトル
  (旋回は各足の接線方向成分、腰ロールIKは閉形式で解く)
- 5節リンクの可動域解析による自動最適化: ストローク60mm・持ち上げ12mm・
  特異点余裕sin>0.30 (fivebar.py GaitPlanner)
- 実測性能 (1.4Hz): 前進 146mm/s / その場旋回 53deg/s / 横歩き 65mm/s
- 腰ロール使用量: 最大約8deg (可動域±40degに対し十分な余裕)
